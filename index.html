Metodologi

01 — BASELINE

λ₀ dasarian

Rerata klimatologi tiap dasarian (36 periode) dari file baseline Anda dipakai sebagai parameter dasar Poisson.

02 — KOREKSI ENSO

Faktor koreksi

Indeks ENSO bulanan dikalikan sensitivitas musiman k (lebih besar saat puncak kemarau), menggeser λ naik/turun.

koreksi = 1 − (k × ENSO)
λ' = MAX(λ₀×0.25, λ₀×koreksi)
03 — DISTRIBUSI POISSON

Proyeksi & selang

λ' jadi parameter Poisson. Nilai ekspektasi = λ'. Selang P10–P90 didekati normal karena λ cukup besar.

P10 = λ' − 1.2816×√λ'
P90 = λ' + 1.2816×√λ'
